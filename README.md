### About me

Final-year **B.Tech in Electronics and Communication Engineering** at **VIT Vellore** (2023–2027, CGPA 8.05).
I take digital designs all the way to hardware: RTL, verification against a golden model, timing closure, and debugging the problems that only show up on the board.

- 🔬 Research intern, **IIT Madras** (May–Jul 2026): parallel GPS C/A code acquisition engine on an Artix-7 FPGA
- 🔧 Embedded systems intern, **C Systems Pvt Ltd, Chennai** (May–Jul 2025): PIC-based industrial temperature monitoring firmware
- 🚗 Working on **physical-layer CAN-bus intrusion detection** using ECU voltage fingerprints
- 📡 IoT with ESP32 training, **COGTIS Technologies** (Mar 2024)
- 💼 Looking for **full-time roles (2027)** or **internships that lead to a full-time offer** in FPGA/RTL design, design verification, embedded firmware and automotive electronics, in **Chennai or Bengaluru**

### Featured work

| Project | What it is | Stack |
|---|---|---|
| [**GPS C/A Code Acquisition Engine**](https://github.com/gogulavanis2023-ui/fpga-gps-ca-code-acquisition) | Up to 32 runtime-selectable parallel correlators with a G1/G2 LFSR PRN generator; one bitstream covers every search-speed vs. resource trade-off; timing met with +5.85 ns slack | Verilog, Vivado, Artix-7, MATLAB |
| [**Reconfigurable Parallel FIR Filter**](https://github.com/gogulavanis2023-ui/fpga-reconfigurable-fir-filter) | 48-tap Q1.15 filter with runtime-selectable parallelism; bit-exact against a Python golden model; ~7× lower energy per sample at full parallelism | Verilog, Vivado, DSP48, Python |
| [**CAN-Bus Voltage Fingerprinting IDS**](https://github.com/gogulavanis2023-ui/can-ecu-voltage-fingerprinting-ids) | Identifies which physical ECU sent each CAN frame; 3-node MCP2515 bench, STM32 guardian, digital twin with open-set SVM and CUSUM (99.5 % unknown-device detection in simulation) | CAN, STM32, Arduino, scikit-learn |
| [**Async FIFO with Gray-Code CDC**](https://github.com/gogulavanis2023-ui/async-fifo-cdc-verilog) | Dual-clock FIFO with Gray-code pointers, 2-FF synchronisers, asynchronous clock groups in SDC, and a scoreboard testbench | Verilog, Quartus, Cyclone IV |
